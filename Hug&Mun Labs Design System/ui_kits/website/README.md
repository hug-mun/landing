# Website UI kit — hug&mun labs

The marketing surface. Home, about, research index, single research page.

## Components
- `Header.jsx` — primary nav with logo lockup
- `Hero.jsx` — two-column "thought / memory" hero
- `ResearchCard.jsx` — card for the research grid
- `Footer.jsx` — flat, no blur
- `ThoughtMemoryGrid.jsx` — a bento-like split showing the duality motif

## Screens (interactive)
1. **Home** — hero, manifesto, research grid, footer
2. **About** — "the two ravens" narrative + team
3. **Research index** — filterable card grid
4. **Paper** — long-form reading layout

Run `index.html` to toggle between screens.
