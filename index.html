Core thesis

Intelligent systems require interaction between semantic interpretation, structured memory dynamics, and belief-driven decision policies.

Current AI systems largely collapse these components into a single neural representation, limiting their ability to maintain stable beliefs across time. hug&mun studies architectures that separate and integrate these functions explicitly.

Most modern AI systems operate as next-token predictors. They produce fluent outputs, but they do not reliably maintain stable internal states, explicit commitments, traceable uncertainty, or consistent decision criteria. The result: they are weak at multi-step reasoning, decision consistency, evidence accumulation, and adaptive planning.

We believe the problem is representational, not one of scale. LLMs represent meaning implicitly in high-dimensional activations — representations that are hard to update incrementally, cannot track uncertainty, and do not persist commitments over time. Decision systems require persistent structure, revisable commitments, and explicit conditions.

Current LLM pipelines collapse or skip these layers. We hypothesize that separating semantic interpretation, memory dynamics, and belief integration produces more reliable, interpretable decisions.

Huginn · Semantic interpretation

How machines interpret meaning.

Transforms language, perception, or data into structured semantic elements. Huginn extracts structured meaning from raw input — not embeddings, not token sequences, but discrete semantic units that isolate individual conditions from evidence.

Our Gentags paper addresses this layer: a candidate implementation of Huginn.

Muninn · Memory dynamics

How machines accumulate experience.

Muninn is not a database. Muninn is structured, evolving context. Grounded in Retrieved Context Models (Lohnas & Daw), we treat memory as a dynamic latent state — a context vector that drifts over time and is updated by experience.

RCM shows that context determines what is retrieved, what is weighted, and what is predicted. This produces recency effects, semantic clustering, and temporal structure — phenomena that demonstrate memory is structured, not passive.

Odin · Belief & decision

How machines maintain internal position.

Odin does not directly observe the world — he depends on internal representations. This is exactly the structure of model-based cognition. The Odin layer integrates semantic evidence (Huginn) with evolving context (Muninn) to form belief states and generate decision policies.

Belief is not identical to memory. Memory provides structure, recall bias, weighting, and temporal ordering. Belief provides commitment, uncertainty, and decision relevance. The distinction matters.

First paper · Huginn layer

Gentags

Gentags are not the final contribution. They are a candidate semantic state representation — the first implementation of the Huginn layer — testing whether structured semantic units improve decision behavior.

We introduce a representation that compresses source text into short, evidence-grounded semantic units — discrete, individually addressable units that fit within the context window of a downstream model. Gentags improve agreement with full-evidence decisions to 79.5% (vs. 52.3–61.6% for lexical baselines) and raise hard-constraint satisfaction to 97.3%.

The next step: demonstrating context dynamics over multiple steps — the Muninn layer.

Testable hypotheses

What we're testing

H1

Structured semantic state improves decision stability.

H2

Belief-state representations improve multi-step reasoning.

H3

Explicit belief revision improves adaptability to new evidence.

H4

Decision policies grounded in belief states are more consistent than token-level reasoning alone.

What most research focuses on

Better embeddings, larger models, better corpora, tool use, prompt engineering.

Few programs focus explicitly on belief as a computational object. Most treat memory as retrieval, not as evolving context that shapes cognition.

What hug&mun focuses on

Cognitive architecture principles.

Three layers — semantic representation, context dynamics, belief updating — explicitly integrated. Grounded in computational cognitive neuroscience, not just scaling.

Long-term vision

AI systems that do more than produce plausible text.

  • Track commitments
  • Revise beliefs
  • Justify decisions
  • Adapt to evidence

This is an ambitious thesis but not unrealistic. It sits between machine learning, cognitive science, and decision theory. Our first paper addresses the semantic representation layer (Huginn). Future work addresses context dynamics (Muninn) and belief integration (Odin) — each layer must produce measurable differences in behavior, or it remains metaphor.
